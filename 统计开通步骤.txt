--------------------------------------------------------
 取数：以后每次想看数据，跑这个
--------------------------------------------------------

  【最简单的办法】

    双击项目根目录里的   run-stats.bat

  它会自己找 Python、跑脚本、把结果显示出来，
  跑完停住不关窗口。不用记命令。

  【或者用命令行】

    cd /d D:\website\MyGallery
    python stats\pull_stats.py

  （如果提示"python 不是内部或外部命令"，就用上面的
    run-stats.bat，它能自己找到 Python。）

  第一次会让你粘贴那个 STATS_KEY（就是你在 Cloudflare
  设的那串，输入时屏幕不显示、不会留痕），之后自动记住，
  不用再输。


--------------------------------------------------------
 数据落在哪
--------------------------------------------------------

    stats\reports\日期-统计报表.md      <- 直接看这个就行
    stats\reports\日期-按天.csv
    stats\reports\日期-下载排行.csv
    stats\data\events.jsonl             <- 原始事件存档，只增不减
    stats\.secret                       <- 你那个密钥，只在本机

  报表里有三块：
    总览        PV / UV / 下载点击数 / 下载访问比
    按天       每天的 PV、UV、下载点击
    下载排行    哪张作品被下载得最多（TOP 30）

  以上目录全部在 .gitignore 里。仓库是公开的，这些绝不会
  被提交上去 —— 这一点我验过了。


--------------------------------------------------------
 常用命令
--------------------------------------------------------

    python stats\pull_stats.py                  平时就用这个（增量）
    python stats\pull_stats.py --full           从头重拉一遍
    python stats\pull_stats.py --from 2026-10-01  指定起始日期
    python stats\pull_stats.py --report-only    只用本地数据出报表，不联网
    python stats\pull_stats.py --set-key        换一个密钥

  脚本是增量的：只拉新增的、按事件唯一编号去重，
  重复跑不会重复计数，也不会把存档写乱。


--------------------------------------------------------
 三个要留意的地方
--------------------------------------------------------

  · 报表里会多出 1 条访问记录 —— 那是我部署后做写入测试
    时发的，属正常，忽略即可。

  · 访客去重的"盐"里包含 STATS_KEY。密钥是今天才配上的，
    所以今天之前的访客会被算成"另一批人"，今天这一天的
    UV 会偏高。从明天起就正常了。

  · KV 免费版每天写入上限 1000 次。你个人站的量远远够用，
    只有哪天突然火了才需要留意。


--------------------------------------------------------
 顺带说明（口径）
--------------------------------------------------------

  · 页面只上报、不显示任何数字，访客完全看不到统计存在
  · 不存 IP、不存浏览器标识、不用 Cookie
  · 访客标识是「IP + 浏览器标识 + 当日密钥」的哈希前 12 位，
    每天重新生成且无法反推，所以只能当天去重；
    跨天的总数 = 每天去重后相加
  · 上报失败会被静默丢弃，绝不影响页面显示
  · 天数按东八区切分（不是 UTC，早上 8 点不会突然换日）
  · 想彻底关掉统计：生成页面时加 --no-track
    （例：python build_gallery_v3.py --no-track）
